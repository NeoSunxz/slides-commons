The system

Four principles,
one sign family.

Every sign in the network follows the same four rules, from a bus-stop flag to a forty-metre concourse wall.

  1. 01

    Decide at the door

    Line, direction and exit are answered before the ticket gates, not after.

  2. 02

    One colour per line

    Twelve line colours, used only for lines — never for ads or alerts.

  3. 03

    Numbers over names

    Exits and platforms get numbers that read in any language.

  4. 04

    Light it, then print it

    Back-lit panels for decisions, print for confirmation only.

The system

Today

Fourteen sign styles from six decades

  • Line colours change between bus, tram and metro
  • Exits named after streets that were renamed
  • Platform direction shown only after the gates

Proposed

One family, built from four rules

  • The same twelve line colours on every mode
  • Numbered exits, mapped at street level
  • Direction decided at the station door
