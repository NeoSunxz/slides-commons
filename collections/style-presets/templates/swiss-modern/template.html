Kessling MetroLinea wayfinding02Principles

The system

Four rules for every sign

01

Arrow first

The arrow is read before the words. It leads every sign, on the left.

02

One decision per sign

A sign answers one question. If there are two, there are two signs.

03

Numbers, not colours

Lines are named 1–6. Colour supports the number; it never replaces it.

04

Same height everywhere

Every sign hangs at 2.4 m, so eyes learn where to look.
